# Personal Skills

A collection of personal skills that improve cooperation with AI agents. Each skill provides reusable instructions for how an agent should communicate or work.

## Available Skills

Each skill has its own folder at the repository root containing a `SKILL.md` file.

| Skill | Purpose |
| --- | --- |
| [Concise Communication](concise-communication/SKILL.md) | Keep replies short, clear, and complete. Answer code questions directly without changing the implementation or adding comments unless requested. Applies implicitly whenever the agent speaks to the user. |
| [Code Review](code-review/SKILL.md) | Verify requirements fulfillment, general and logical correctness, tech stack good practices, and consistency with codebase specifications, documentation, and patterns. Applies implicitly whenever code review is performed. |
